# Speaky 桌面版使用指南

在仓库根目录运行 `cargo run --locked --manifest-path speaky-gpui/Cargo.toml`。Windows 首次编译后还可双击仓库根目录的 `start-windows.cmd`。本地 Qwen3-ASR 和麦克风配置见 [Windows 本地运行](../docs/Windows本地运行.md)。

在「设置 → 录音 → 全局快捷键」录入想用的按键，例如 `F8` 或 `Ctrl+Shift+R`。按一次立即开始录音，松开后可以继续说话，再按一次停止并保存。持续按住只触发一次。Windows 的初始快捷键是 `Ctrl+Shift+空格`，macOS 是 `⌥⇧Space`。

首次引导覆盖权限、快捷键、推荐识别语言、麦克风检测、模型选择、首次录音和外部输入演练。macOS 需要开通麦克风与辅助功能权限。引导可随时跳过，主界面左下角的「进入引导」可随时重新开始。

主窗口的「停止并保存」和波形悬浮条右侧的 `✓` 都会先保存音频，再完成转写。悬浮条左侧 `✕` 或 `Esc` 取消本次转写，并在保护原有输入和手动编辑的前提下清除中间预览；原始录音仍保存在历史中。切换应用、切换桌面或最小化主窗口时，录音仍在同一会话中。主窗口的关闭按钮会最小化窗口。Windows 可点击侧栏「退出 Speaky」或按 `Ctrl+Q`，macOS 可按 `⌘Q` 退出。退出时也会保存正在录制的音频。

侧栏「设置」可更改录音快捷键、输入设备和识别语言。Windows 快捷键为 `Ctrl+,`，macOS 为 `⌘,`。首页与设置显示当前麦克风、音量条和 ASR/LLM 模型；macOS 也显示辅助功能状态。「测试麦克风」会检查权限并采集约三秒声音，区分可用、有设备但未检测到声音、权限未开通和设备错误。要切换识别服务，在「识别 → 接入方式」填写服务地址、所需的模型 ID 和 API 密钥。Speaky 通过内置的两秒中文语音检测接入方式和转写可用性。「检测可用性」可再次测试当前服务。

在外部输入框听写时，按全局快捷键开始说话，录音期间可以切换到其他应用或输入框，再按一次结束。Speaky 以停止时聚焦的可写输入框为最终目标，保留原有文字和手动编辑，由用户决定是否发送。成功写入后恢复用户原有剪贴板；若没有可写输入框或无法自动写入，结果会保存到剪贴板和历史，并弹出「语音识别内容已保存到剪贴板，请手动粘贴」提醒。

从 Speaky 首页开始的录音始终边录边转写：当次录音的短片段送给当前识别引擎，文字陆续出现在「听写预览」中，无需手动开启。点击「停止并保存」后先保存完整 WAV，再自动生成最终 ASR 文字，并按设置进行语音整理。首页录音的结果保存在应用中，可从首页或历史复制。

录音期间每两秒尝试原子保存一次 WAV 快照。停止、退出或识别失败后，原录音保留在历史里，支持播放、「重新转写」，以及继续录制未转写的录音；继续录制保留已有音频。取消转写的录音和旧版本标为已取消的录音也仍可使用。保存失败会提示重试，音频保留在内存中。首页显示录音数量、总时长、转写字符数和近七天活动。文件位于 Speaky 配置目录的 `drafts` 子目录。

常用词每行一个，或用 `误识别词 => 正确写法` 添加替换规则。所有引擎支持本地替换。已确认支持 `prompt` 的 Whisper 服务可以设置 `engine.openai.use_vocabulary_prompt: true`，把常用词作为识别提示发送。当前内网 SenseVoice 配置使用本地替换。火山引擎可用 `SPEAKY_VOLC_API_KEY` 环境变量配置。

开发运行时，由 macOS 控制启动该程序的终端进程及应用的麦克风访问。在「系统设置 → 隐私与安全性 → 麦克风」里检查权限。

## 可选语音整理

在「设置 → 语音整理」编辑并启用独立的 OpenAI 兼容模型（建议开启），基础地址需要包含 API 前缀（例如 `/v1`）。启用后，每次完整转写先保存 ASR 原文，再自动调用整理模型；全局听写优先写入整理稿，大模型调用失败则自动降级使用 ASR 原文。Speaky 只向整理服务发送文字；原始音频、ASR 原文和最新整理稿分别保存，互不覆盖。也可在历史里悬停于已转写的条目，点击「整理」再次生成。

「测试大模型」通过同一个聊天补全接口发送三条固定的合成转写，统一使用「自然整理」的提示词。报告逐条展示原文、整理稿、耗时和未通过的事实检查，可用于比较模型。自动检查达到 85 分且关键事实全部通过时标记为通过，文笔和自然程度可结合结果人工判断。

在「设置 → 语音整理」开启「Debug 模式」后，之后的整理调用会为对应历史条目保存脱敏请求记录。点击该条目的「查看改写请求」，可查看实际模型名、系统提示词、输入文字及调用错误。记录不保存 API Key 或请求头，并会遮蔽这些字段中出现的已配置密钥，便于复现问题。

偏好评分默认跳过，内置提示词使用「自然整理」。在「设置 → 语音整理」开启评分后，可以给内置提示词生成的整理稿评「好」或「不好」，也可以随时跳过。评分在本地按服务地址、模型和风格保存。Speaky 优先试用已评样本较少的风格，同一风格收到至少 5 条不同录音的评分且好评率达到 80% 后，后续整理会使用该风格，也可在设置中复制其提示词。候选风格为「自然整理」「贴近原话」「条理清晰」。

「添加提示词」可从内置范例开始修改，也可以粘贴自己的提示词。保存后可继续编辑。自定义提示词优先用于日常整理，期间暂停偏好评分。选择「恢复内置」即可回到原来的评分设置，已有评分会保留。

## 内网 ASR 联调

应用读取 `~/Library/Application Support/speaky/config.yaml`。可合并以下字段，启用 `gpu11` 上的 SenseVoice-Small CPU 服务。录音会发送到该内网服务，`EMPTY` 是兼容适配器的占位值。

```yaml
engine:
  current: openai
  openai:
    base_url: http://127.0.0.1:8201/v1
    model: sensevoice-small
    api_key: EMPTY
```
