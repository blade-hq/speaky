## 1. 背景与设计目标

旧版 Speaky 桌面端存在入口重复（首页 2×2 快捷卡片与左侧栏重叠）、状态以大段文本堆砌、设置页单页过长、以及向用户暴露过多底层技术概念（如 `packs/` 目录、启动模型、剪贴板清理开关等）的问题。

本次重排的目标：
1. **克制与高信噪比**：参考 Typeless 与 Spokenly 的桌面端视觉节奏，用图标、按钮与紧凑布局引导操作，避免文字堆砌。
2. **功能闭环与零丢失**：所有操作围绕「随时听写、绝不丢音、易于排障、断网可用」展开。
3. **跨平台通用语义**：去除 `访达` 等单一系统专属文案；权限与快捷键按当前操作系统自动适配。
4. **工程可落地**：业务状态、洞察统计、模型适配与协议探测全部下沉至 `speaky-core`，UI 层只做展示与交互编排。

## 3. 各板块详细设计与计算机制

### 3.1 首页（三栏结构）

首页定位为「打开主窗口时的状态总览与轻量工作台」，平时用户主要通过全局快捷键跨应用听写。

#### 3.1.1 顶栏与零干扰应用内录音
- 顶部主标题「说话，不要打字」，右侧提供轻量主按钮「开始录音」。
- 点击后**原地平滑展开**边录边转写条（实时波形 + 计时 + 流式预览文字），主按钮切换为红色「■ 停止并保存」，旁侧出现「✕ 取消」。
- **零丢失机制**：点击「✕ 取消」或按 `Esc` 立即清除实时预览文字，但原始音频仍落盘至本地历史并标记为「待转写」。

#### 3.1.2 中间画布：洞察（Insights）与 7×20 热力图
所有统计指标下沉至 `speaky-core` 新增的 `insights` 聚合模块，**不依赖仅保留 50 条的 `history.json`**，而是基于本地录音目录（WAV + 侧车 JSON）按**本地自然日**去重聚合。

| 指标 | 计算公式与口径说明 |
| --- | --- |
| **口述字数** | 累计所有有效转写记录的最终文本字符数（中文按单字计数，英文按词或非空白字符统一口径，优先取改写稿，无改写稿取 ASR 原文；不含纯空白与标点噪音）。 |
| **总口述时间** | 累计所有有效转写记录的原始音频时长 $\sum d_i$（直接读取 WAV 头或侧车记录的 `duration_ms`，以录音实际时长为准）。 |
| **平均口述速度** | $\text{口述字数} / (\text{总口述时间（分钟）})$；仅统计同时具备有效文本和有效时长（$>0$）的样本，保证分子分母一致。 |
| **节省时间** | 对比基准打字速度 $v_{\text{type}} = 40\text{ 字/分钟}$ 计算：$\max\left(0,\ \frac{\text{口述字数}}{v_{\text{type}}} - \text{总口述时间}\right)$。UI 保持简洁仅显示「节省时间」。 |
| **活跃天数** | 本地时区下，至少存在 1 条有效听写记录的不同自然日总数。 |
| **当前连续天数** | 从今天（若今天暂无记录则从昨天起算）向前连续每天均有记录的天数。 |
| **最长连续天数** | 历史所有自然日中，连续有记录的最大跨度天数。 |
| **7×20 活跃热力图** | 展示最近 20 周（140 天，按周一至周日 7 行排布）的每日口述字数强度。色阶分 5 档：`0`（无记录）、`L1`（1–499 字）、`L2`（500–1499 字）、`L3`（1500–2999 字）、`L4`（$\ge 3000$ 字）。未来日期格置灰透明占位。 |

> **关键边界**：对历史录音执行「重新转写」会更新 `recognized_at`，但统计归属日期**固定按原始录音创建时间（本地日）**，避免重转写污染当天热力图。

#### 3.1.3 右侧功能栏（232px）
1. **快捷键卡**：全局听写键帽（macOS `Right Option` / Windows `Ctrl + Shift + D`）、`Esc` 取消保留原音、一键切换推荐识别语言。
2. **运行状态卡（状态可见性与排障）**：
   - 顶部标题行集成 **「全链路体检」** 按钮（依次检测权限 → 麦克风采集 → 当前 ASR → 当前 LLM 改写）。
   - 权限状态（macOS 显示 `麦克风 · 辅助功能`，Windows 显示 `麦克风权限`）+ 状态灯。
   - 当前麦克风 + 实时环境音量电平条 + `测麦` 按钮。
   - 当前听写模型 + `测试` 按钮；当前改写模型 + `测试` 按钮（关闭时标黄提示「未开改写（建议开启）」）。
3. **最近转写预览卡**：支持 `改写 / 原文` 一键切换、原音回放、复制，点击正文直达历史记录。

### 3.2 AI 模型（统一列表 × 开源下载与在线连接闭环）

- **设计理念**：
  - 不按「本地 / API」拆分页签，用户只需按用途在 **`听写（ASR）`** 与 **`AI 处理（改写）`** 之间切换。
  - 每个模型标题行明确打上 **`本地模型` / `在线模型`** 标签以及状态标签（`已就绪` / `已下载` / `已连接` / `下载中`）；描述下方仅放可点击动作（`测试`、`配置`、`测试连接`、`↓ 下载`），做到「状态在上、动作在下」。
  - **不暴露「启动模型」与 `packs/` 技术概念**：开源模型下载完成后即点即用，后台由 `speaky-core` 自动拉起/切换推理进程。

#### 3.2.1 听写（ASR）默认模型梯度
- **纯 CPU 跨平台开源底座**：统一基于 **`sherpa-onnx`**（纯 CPU、零 Python 运行时依赖，覆盖 macOS / Windows / Linux；Win7 通过独立 CPU 子进程兼容）：
  1. **Qwen3-ASR-0.6B（本地模型 · 推荐）**：中英混排与方言准确度出色，桌面多核 CPU 均衡主力。
  2. **SenseVoice-Small（本地模型 · 最快）**：非自回归架构，纯 CPU 毫秒级出字，老旧电脑无压力。
  3. **Qwen3-ASR-1.7B（本地模型 · 高精度）**：开源第一梯队准确度，适合复杂专业术语与会议录音转录。
- **预置在线服务**：
  4. **火山 Doubao-语音识别（在线模型）**：复用现有 `VolcBigModelEngine`，支持流式实时识别。

#### 3.2.2 模型下载引导与「立刻试用」小弹窗
- 点击未下载开源模型后，弹出紧凑居中的下载进度小弹窗（品牌 Logo + `正在下载 <模型名>` + 实时进度条 + `已下载 MB / 总大小 MB` + `%` + 右上角 `✕` 取消）。
- 下载并校验完成后，**原地切换为「立刻试用」小弹窗**：展示「按住 / 轻按」双行快捷键提示（按系统自动适配）+ 聚焦输入框「你说的话会显示在这里…」，让用户第一时间验证新模型效果。
  - *工程注意点*：macOS 跨应用投递默认跳过本进程，Windows 也需显式识别试用框焦点；写入前复核焦点状态，试录同样遵守先存原音红线。

#### 3.2.3 「+ 连接自定义 API」闭环（对齐 `speaky-core`）
- **协议自动探测（默认推荐）**：复用 `engines/detect.rs` 的 `detect_service`，根据协议头（`ws://`/`wss://` → `FunASR WebSocket`）及实际探活自动识别 `OpenAI 兼容转写` / `FunASR WebSocket` / `whisper.cpp 原生 HTTP`，同时保留手动切换选项。
- **测试连接**：使用内置样例 WAV 实际发起一次试转写，成功后再标为「已连接」。
- **下载测试包（`.zip`）**：一键导出包含固定测试音频 `sample.wav` 与与 Speaky 请求完全一致的 Python 复现脚本（`test_asr.py` / `test_llm.py`，不含明文密钥），方便开发者和企业自建网关排障。

#### 3.2.4 高级（离线导入 / 导出）
- 仅在「听写（ASR）」列表底部提供可折叠的 **「高级（离线导入 / 导出）」**，面向断网环境用户形成闭环：
  - **导出离线模型包**：联网机下载后打包导出（含模型权重与校验清单）。
  - **导入离线模型包**：断网机直接导入并校验完整性与 OS/架构匹配，无需联网。

#### 3.2.5 AI 处理（改写）
- 仅支持远程 **Chat Completion 兼容接口**（不提供本地 LLM 选项），默认预置 **DeepSeek** + **自定义接口**。
- 顶部右侧提供 **「已开启改写 / 已关闭改写（建议开启）」** 开关，关闭后列表置灰，与首页状态卡实时联动。

### 3.3 转录文件
- 居中拖拽上传区，支持常见音视频格式（`MP3, WAV, M4A, FLAC, OPUS, OGG, MP4, MOV, M4V`），提供「选择文件…」与「录制音频」按钮。
- **工程实现路径**：在 `speaky-core` 中引入通用音频解封装与重采样层（转换为 16kHz 单声道 PCM WAV），对长文件做静音检测分段转写；支持后台取消，取消或失败均保留源文件与记录供重试，完成后自动归档至「历史记录」。

---

### 3.4 历史记录
- **按日期分组的紧凑单行列表**（`今天` / `昨天`…），默认每行仅展示「时间 + 正文」（单行高信噪比，无多余副行）。
  - 待转写/已取消记录：正文提示「转录已被取消（原音已留存）。」，右侧常显 **`↻ 重试`** 按钮。
  - 普通记录：hover 展示复制、播放原音、`...` 更多菜单（含重新转写、查看原文/改写、下载音频、删除记录）。
- **实时搜索 + 短标签筛选**：顶部提供 `全部` / `待转写` / `已改写` / `仅原文` 分段筛选与实时搜索框（支持中文 IME 输入，按正文/原文/时间过滤）。
- **三层独立展开**：点击任意行展开详情抽屉，独立展示 **改写稿**、**ASR 原文** 与 **Debug 脱敏请求详情**（开启 Debug 模式时显示脱敏 API Key、模型名、系统提示词与输入）。

### 3.6 设置（单页四分组）
参考 Typeless 的极简分组布局，去掉冗余二级 Tab 与内置默认行为开关（如剪贴板自动清理无需暴露开关）：
1. **快捷键**：语音输入（点击改键）。
2. **语言**：推荐识别语言。
3. **音频**：麦克风（下拉 + 测试）、交互声音（提示音开关）、语音输入时静音（**默认关闭**，规避异常退出后系统音量未恢复风险）。
4. **常规**：外观（深色 / 浅色，联动全局含悬浮窗）、登录时启动应用、Debug 模式。
