## 本地验证

- `cargo test --workspace --locked`：105 项通过（核心库 87、GPUI 18），0 失败。
- `cargo build --locked -p speaky-gpui`：通过。
- Win7 专用目标本地构建通过，打包检查验证 Windows GUI 子系统版本 6.01。
- `git diff --check`：通过。
- Windows 副屏测试使用独立配置/历史目录、真实麦克风和本机模拟 ASR/LLM 服务，不测试真实服务的识别准确率。
- 已通过的应用场景：副屏启动、取消保留录音、音频/原文/改写稿独立保存及改写优先写入、LLM 失败降级、停止后焦点变化时剪贴板提醒、Esc 取消、关闭时保存、首次引导。
- 最终构建另行完成混合 DPI 悬浮条显示与应用内取消保存复测，确认左右按钮完整可见。

- macOS 修改已做源码复核；此 Windows 环境未运行 macOS 构建及实机测试。

## 复测入口

`scripts/qa-product-invariants.py` 必须使用副屏；`--app-only` 验证应用流程，`--layout-only` 使用应用内按钮复测多屏布局。输入框测试需要系统前台焦点保持在测试窗口。无副屏或无法访问交互桌面时跳过 GUI，不使用主屏。
